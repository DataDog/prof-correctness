# PR-171 — stack-advanced + alloc gate scenarios (3.14/3.15)

**Prev:** [#169](https://github.com/DataDog/prof-correctness/pull/169) (merged) | **Next:** [#172](https://github.com/DataDog/prof-correctness/pull/172)

**Base:** `main` (includes merged #169 cpu gate)

## Motivation

**Alloc** (`alloc-space` / `alloc-samples`) plus stack-profiler edge cases — **asyncio task labels**, **native C frames**, **deep unwinding** — for the Python 3.14/3.15 migration gate (PROF-15511).

## Summary

Four scenario families × two Python versions (**8 scenario dirs**):

| Family | Directories | Profile focus |
|--------|-------------|---------------|
| alloc | `python_alloc_3.14` / `_3.15` | alloc-samples + alloc-space (1:3 byte ratio) |
| asyncio | `python_asyncio_3.14` / `_3.15` | wall-time + task-name labels |
| native_cpu | `python_native_cpu_3.14` / `_3.15` | cpu-time + wall-time, C-extension frames |
| deep_stack | `python_deep_stack_3.14` / `_3.15` | cpu-time, deep unwind + omitted frames |

Downstream gate default set: **18 scenarios** (9 families × 3.14/3.15) per [`python_downstream_gate/README.md`](../scenarios/python_downstream_gate/README.md).

**Commits of note:** dedupe symlinks `937f7b8` · burn-in 3.14 `04d8710` · typing `5d6758f` · README layout `e875ae5` · asyncio ±5 `08caf9b`

## Layout

Canonical trees hold workload + expectations; version dirs symlink profiles and keep real Dockerfiles:

```
scenarios/python_{alloc,asyncio,native_cpu,deep_stack}/
├── main.py
├── profile.json              # 3.14 (+ asyncio/native/deep 3.15)
├── profile_3.15.json         # alloc 3.15 only
└── requirements.txt → ../python_gate/requirements.txt

scenarios/python_{family}_3.{14,15}/
├── Dockerfile                # real (3.14 PyPI / 3.15 wheel base)
├── README.md
└── expected_profile.json → ../python_{family}/profile.json
                            # alloc 3.15 → profile_3.15.json
```

Percent checks: `|expected − actual| ≤ error_margin` (absolute percentage points).

### python_*_3.15 (all four families)

| Scenario | Burn-in | Notes |
|----------|---------|-------|
| `python_alloc_3.15` | **Not burned in** | `expected_profile.json` → `profile_3.15.json` (pre-tuned for downstream); no local/CI run on `main` |
| `python_asyncio_3.15` | **BLOCKED** | `ModuleNotFoundError: ddtrace` without wheel base |
| `python_native_cpu_3.15` | **BLOCKED** | same |
| `python_deep_stack_3.15` | **BLOCKED** | same |

**3.15 blocker:** `DDTRACE_INSTALL_URL` wheel ships **cp315 musllinux only** (no `manylinux2014_x86_64` for 3.15). `python:3.15` Debian base cannot install; needs manylinux cp315 wheel or musl base image change.
